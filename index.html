The Core Tags
of HTML, Reviewed

A reference built page by page: structure, text, links, lists, tables, forms, multimedia, semantics and metadata — each tag with its definition, attributes and a live example.

<!DOCTYPE html>

Definition

Declares the document as HTML5 so browsers render it in standards mode. It is not a tag with a closing pair — it's the very first line of the file.

Example (code)

<!DOCTYPE html>
<html lang="en">
  ...
</html>

Example (result)

No visible output — it only sets the parsing mode.

<html>

Definition

The root element that wraps every other element on the page.

Attributes

AttributeRole
langDeclares the page's language, e.g. en or fr.

Example (code)

<html lang="en">
  <head>...</head>
  <body>...</body>
</html>

Example (result)

The root container — nothing to display on its own.

<head>

Definition

Holds information about the document that isn't shown directly on the page: title, metadata, links to stylesheets.

Example (code)

<head>
  <meta charset="UTF-8">
  <title>My Page</title>
  <link rel="stylesheet" href="css/style.css">
</head>

Example (result)

Invisible — sets the browser tab title and loads resources.

<body>

Definition

Contains everything that is visible on the page: text, images, links, forms.

Example (code)

<body>
  <h1>Hello world</h1>
</body>

Example (result)

Hello world
