Lists

<ul / li>

Definition

ul creates an unordered (bulleted) list; each item is wrapped in an li.

Example (code)

<ul>
  <li>HTML</li>
  <li>CSS</li>
</ul>

Example (result)

  • HTML
  • CSS

<ol / li>

Definition

ol creates an ordered (numbered) list, useful for sequential steps.

Attributes

AttributeRole
startSets the number the list starts counting from.

Example (code)

<ol>
  <li>Open VS Code</li>
  <li>Create index.html</li>
</ol>

Example (result)

  1. Open VS Code
  2. Create index.html

<dl / dt / dd>

Definition

A description list pairs terms (dt) with their descriptions (dd).

Example (code)

<dl>
  <dt>HTML</dt>
  <dd>Markup language for structure.</dd>
</dl>

Example (result)

HTML
Markup language for structure.
