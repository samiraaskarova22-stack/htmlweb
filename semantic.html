Semantic & Layout Tags

<header>

Definition

Represents introductory content for a page or section — usually a logo, title, and navigation.

Example (code)

<header>
  <h1>Site Name</h1>
  <nav>...</nav>
</header>

Example (result)

header: logo + nav

<nav>

Definition

Marks a block of navigation links, usually the main menu of the site.

Example (code)

<nav>
  <a href="index.html">Home</a>
  <a href="text.html">Text</a>
</nav>

Example (result)

nav: Home · Text

<main / section / article>

Definition

main holds the page's primary content (once per page); section groups related content; article is self-contained content like a post.

Example (code)

<main>
  <section>
    <article>...</article>
  </section>
</main>

Example (result)

main → section → article

<aside / footer>

Definition

aside holds tangential content like a sidebar; footer holds closing information such as copyright or contact links.

Example (code)

<aside>Related links</aside>
<footer>&copy; 2026 html-review</footer>

Example (result)

aside | footer
