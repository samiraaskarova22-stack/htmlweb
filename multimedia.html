Multimedia

<video>

Definition

Embeds a video player directly in the page, with native browser controls.

Attributes

AttributeRole
srcPath to the video file.
controlsShows play/pause/volume controls.
autoplayStarts playback automatically (often muted).

Example (code)

<video src="images/clip.mp4" controls width="240"></video>

<audio>

Definition

Embeds a sound or music player with native controls.

Attributes

AttributeRole
srcPath to the audio file.
controlsShows the play/volume controls.

Example (code)

<audio src="images/sound.mp3" controls></audio>

<iframe>

Definition

Embeds another HTML document inside the current page, such as a map or an external video.

Attributes

AttributeRole
srcURL of the page to embed.
width / heightSets the size of the embedded frame.

Example (code)

<iframe src="https://example.com" width="240" height="120"></iframe>
