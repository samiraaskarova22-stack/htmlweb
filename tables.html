Tables

<table / tr / td>

Definition

table defines a data table; each row is a tr, and each cell inside a row is a td.

Example (code)

<table>
  <tr>
    <td>Row 1, Col 1</td>
    <td>Row 1, Col 2</td>
  </tr>
</table>

Example (result)

Row 1, Col 1Row 1, Col 2

<th>

Definition

Defines a header cell, shown bold and centered by default, used for column or row titles.

Attributes

AttributeRole
scopeDeclares whether the header applies to a col or row.

Example (code)

<table>
  <tr>
    <th>Attribute</th>
    <th>Role</th>
  </tr>
</table>

Example (result)

AttributeRole

<thead / tbody>

Definition

thead groups the header row(s); tbody groups the main data rows — useful for styling and semantics.

Example (code)

<table>
  <thead>
    <tr><th>Name</th></tr>
  </thead>
  <tbody>
    <tr><td>Ana</td></tr>
  </tbody>
</table>

Example (result)

Name
Ana
