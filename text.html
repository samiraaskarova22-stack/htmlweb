Text Formatting Tags

<h1–h6>

Definition

Headings of decreasing importance, from h1 (main title) to h6 (smallest). Used to structure the page outline.

Example (code)

<h1>Main Title</h1>
<h2>Section Title</h2>

Example (result)

Main Title

Section Title

<p>

Definition

Defines a paragraph of text — a block-level container for a chunk of content.

Example (code)

<p>This is a paragraph of text.</p>

Example (result)

This is a paragraph of text.

<strong / em>

Definition

strong marks text as important (shown bold); em marks text with stress emphasis (shown italic).

Example (code)

<strong>Important</strong> and <em>emphasized</em> text.

Example (result)

Important and emphasized text.

<span>

Definition

An inline, generic container with no semantic meaning — used to style or target a piece of text.

Attributes

AttributeRole
classAttaches a CSS class to style the span.

Example (code)

<p>Some <span class="highlight">highlighted</span> text.</p>

Example (result)

Some highlighted text.

<br / hr>

Definition

br inserts a single line break inside text; hr draws a horizontal rule to separate content.

Example (code)

Line one<br>
Line two
<hr>

Example (result)

Line one
Line two
