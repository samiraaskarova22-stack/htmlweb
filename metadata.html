Metadata

<title>

Definition

Sets the text shown in the browser tab and used by search engines — placed inside head.

Example (code)

<title>HTML Review</title>

Example (result)

Invisible on page — shown only in the browser tab.

<meta>

Definition

Provides metadata about the document, such as character encoding or a page description, invisible to the reader.

Attributes

AttributeRole
charsetDeclares the character encoding, e.g. UTF-8.
name / contentA key-value pair, e.g. description of the page.

Example (code)

<meta charset="UTF-8">
<meta name="description" content="A review of HTML tags.">

Example (result)

Invisible — read by browsers and search engines.

<link>

Definition

Links an external resource to the document, most commonly a CSS stylesheet.

Attributes

AttributeRole
relRelationship to the document, e.g. stylesheet.
hrefPath to the linked file.

Example (code)

<link rel="stylesheet" href="css/style.css">

Example (result)

Invisible — loads the shared stylesheet.
