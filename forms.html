Forms

<form>

Definition

Wraps a group of input controls that are submitted together to a server.

Attributes

AttributeRole
actionThe URL the form data is sent to.
methodHTTP method used to send data, e.g. get or post.

Example (code)

<form action="/submit" method="post">
  ...
</form>

Example (result)

A container — nothing visible by itself.

<input>

Definition

A single-line form control; its type attribute decides whether it's text, a checkbox, a date, etc.

Attributes

AttributeRole
typeKind of control: text, email, checkbox, radio…
nameKey used to identify the value when submitted.
placeholderHint text shown when the field is empty.

Example (code)

<input type="text" name="username" placeholder="Your name">

Example (result)

<label>

Definition

Attaches a text description to a form control, improving accessibility and clickability.

Attributes

AttributeRole
forMatches the id of the input it describes.

Example (code)

<label for="email">Email</label>
<input id="email" type="email">

Example (result)

<select / option>

Definition

select creates a dropdown; each choice inside it is an option.

Attributes

AttributeRole
valueThe value sent for that option when selected.

Example (code)

<select name="level">
  <option value="beginner">Beginner</option>
  <option value="advanced">Advanced</option>
</select>

Example (result)

<button>

Definition

A clickable control, typically used to submit a form or trigger an action.

Attributes

AttributeRole
typesubmit, reset, or button.

Example (code)

<button type="submit">Send</button>
