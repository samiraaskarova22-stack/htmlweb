Links & Images

<a>

Definition

Creates a hyperlink to another page, section, or external site.

Attributes

AttributeRole
hrefThe destination URL or anchor.
targetWhere to open the link, e.g. _blank for a new tab.

Example (code)

<a href="https://example.com" target="_blank" rel="noopener noreferrer">Visit example</a>

Example (result)

Visit example

<img>

Definition

Embeds an image into the page. Self-closing — it has no closing tag.

Attributes

AttributeRole
srcPath or URL to the image file.
altText description shown if the image fails to load.
width / heightSets the display size of the image.

Example (code)

<img src="images/logo.png" alt="Site logo" width="80">

Example (result)

img

<a (anchor link)>

Definition

A link can also jump to an element on the same page by targeting its id.

Attributes

AttributeRole
href="#id"Scrolls to the element with that id.

Example (code)

<a href="#top">Back to top</a>
